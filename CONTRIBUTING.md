# Contributing

This is a public training repository. Each learner should submit one pull request changing exactly one file: `learners/<your-github-username>.md`. Copy `learners/TEMPLATE.md` and keep the three headings in order. Keep the file below 2 KB. Do not include contact details, passwords, client information or other private data.

The pull request check is required before a reviewer can merge. Reviews are supportive practice. Opening a pull request is enough for the Hub quest once its check passes; merging is not required.
