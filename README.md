# Cloud Crew onboarding sandbox

Welcome! This public practice repository is a safe place to try one small GitHub pull request. Do not add passwords, contact details, client data or anything private.

1. Sign in to GitHub and choose **Fork** to make your own copy.
2. In your fork, create a new branch from `main` for this exercise.
3. Copy `learners/TEMPLATE.md` to `learners/<your-github-username>.md`. Use your exact GitHub login, including its letter case, in the filename.
4. Fill in the three headings with your name, one thing you want to learn, and your favourite tool. Keep the file under 2 KB. Do not add contact details.
5. Commit the file with a short message, such as `Add my learner introduction`.
6. Open a pull request from your branch to this repository's `main` branch. The **Validate learner file** check will run automatically.
7. When the check passes, return to the Community Hub and choose **Check now** on the practice pull request quest. Leave your pull request open until the Hub confirms it.

If the check fails, open its details, correct your file in the same branch and push another commit. The check will run again. A Cloud Crew reviewer may close practice pull requests after the exercise; no automatic merge is set up.
